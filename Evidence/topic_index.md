# Evidence Topic Index

Use this index before starting new research. Match the project topic to tags, then open `evidence_sources.csv` and `claim_registry.csv` for exact source and claim records.

## Sleep / Bedtime Foods

Tags:
- `sleep`
- `bedtime_food`
- `kiwi`
- `insomnia_caution`

Reusable sources:
- `SRC_SLEEP_KIWI_2011`
- `SRC_SLEEP_AASM_2021`
- `SRC_KIWI_USDA_FDC`
- `SRC_KIWI_ALLERGY_2013`

Reusable claims:
- `CLM_KIWI_SLEEP_ROUTINE`
- `CLM_SLEEP_CARE_CAVEAT`
- `CLM_KIWI_ALLERGY_CAVEAT`
- `CLM_KIWI_NUTRITION_CAUTION`

Notes:
- Kiwi sleep evidence is limited and not senior-specific.
- Always include allergy, diabetes, kidney, potassium, reflux, serious sleep symptoms, and medication caveats when recommending repeated use.

## Blood Pressure / DASH Breakfast

Tags:
- `blood_pressure`
- `hypertension`
- `DASH`
- `low_sodium`
- `breakfast`
- `oats`

Reusable sources:
- `SRC_BP_DASH_NHLBI_2026`
- `SRC_BP_DASH_APPEL_1997`
- `SRC_BP_DASH_SODIUM_2001`
- `SRC_OATS_BETA_GLUCA_2016`

Reusable claims:
- `CLM_DASH_BP_SUPPORT`
- `CLM_DASH_SODIUM_BP`
- `CLM_OATS_CVD_SUPPORT`

Notes:
- DASH supports blood-pressure control, but no breakfast should be framed as a cure.
- Avoid medication alteration language.
- Include kidney disease, potassium restriction, diabetes, allergy, swallowing, dental, and clinician caveats when relevant.
