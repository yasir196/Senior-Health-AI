# 06 — Thumbnail Blueprints

> Permanent internal documentation. Senior Health YouTube Production System.
> This document is standalone and self-contained.

---

## 1. Master Recipe

Dark background + 2–4 huge yellow/red words + one emotional face (right third) + one oversized hero object + one signal icon.

| Parameter | Value |
|-----------|-------|
| Background | Dark (near-black / navy / deep teal) |
| Text words (min–max) | 2–5 |
| Face position | Right third |
| Hero objects | Exactly 1 |
| Signal icons | 1 |

---

## 2. Winning Layouts

| ID | Layout | Use Case | Components |
|----|--------|----------|------------|
| L1 | Object + Screaming Verb + Confident Face | Relief / food topics | Glossy food, red verb, green ✓, smiling presenter |
| L2 | Body-Part Close-up + Red Circle + Alarmed Face | Diagnostic topics | Extreme close-up, red ring, concerned expression |
| L3 | Big Pill/Box + Blue SENIORS Banner + Direct Gaze | Named-drug topics | Oversized drug graphic, blue trust band, direct gaze |
| L4 | Hero Presenter + Bold Personal Claim | Transformation topics | Vigorous senior, big yellow claim, thumbs-up |

**Layout selector:**

| Topic class | Layout |
|-------------|--------|

| diagnostic | L2 |

---

## 3. Color Psychology

| Color | Function |
|-------|----------|
| Red | Danger words, circles, arrows, alarm |
| Yellow | Primary subject headline |
| Green | Safe / good signal (✓) |
| Blue | Trust / authority band ("SENIORS MUST KNOW") |
| Dark base | Contrast to pop yellow/red text |

---

## 4. Doctor Positioning

- Presenter occupies right 35–40%, chest-up, cut out, light-popped off a darker background.
- Gaze either locked on viewer (trust) or directed at the object/text (attention routing).
- Expression exaggerated and unambiguous — alarmed for fear topics, warm/thumbs-up for relief.

---

## 5. Food / Object Positioning

- Exactly one hero object, bottom or opposite corner.
- Oversized (25–40% of frame), glossy, front-lit, instantly recognizable.
- Avoid abstract objects (generic organs, generic pills underperform).

---

## 6. Background Styles

Near-black, navy, or deep teal behind text. Presenter may sit on a lighter/blurred clinical background before compositing.

---

## 7. Object Hierarchy (engineered reading order)

1. Biggest yellow word
2. Red danger/payload word
3. Face / expression
4. Hero object
5. Blue trust band

---

## 8. CTR Patterns & Visual Rules

| ID | Rule | Severity |
|----|------|----------|
| V1 | Dominant word readable at 120px | Block |
| V2 | Exactly one recognizable hero object | Block |
| V3 | No abstract object | Warn |
| V4 | Expression never neutral | Block |
| V5 | One directional cue (arrow/circle/✓/✗) | Warn |
| V6 | Words between 2 and 5 | Block |

---

## 9. Pre-Publish Thumbnail Checklist

- [ ] One dominant word readable on a phone (120px)
- [ ] Exactly one appetizing/recognizable hero object
- [ ] Clear, strong facial emotion (never neutral)
- [ ] Dark background with yellow + red text
- [ ] One directional cue present
- [ ] Maximum 3–5 words

If all six are yes, the thumbnail matches the DNA of proven winners.
