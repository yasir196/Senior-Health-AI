# Pronunciation Dictionary

Use this reusable dictionary when preparing `06b_voice_checklist.md` and reviewing ElevenLabs Studio V3 narration.

The dictionary should grow over time whenever a new difficult medical, supplement, medication, or scientific term appears in an approved script.

## Common Medical and Supplement Terms

| Term | Pronunciation Guidance |
|---|---|
| Amlodipine | am-LOH-di-peen |
| Losartan | loh-SAR-tan |
| Lisinopril | ly-SIN-oh-pril |
| Potassium | poh-TASS-ee-um |
| Electrolytes | ee-LEK-troh-lites |
| Creatinine | kree-AT-ih-neen |
| eGFR | say letters clearly: E G F R |
| Hyaluronic | hy-uh-loo-RON-ik |
| Collagen Peptides | KOL-uh-jen PEP-tides |
| Niacinamide | nye-uh-SIN-uh-mide |
| Magnesium Glycinate | mag-NEE-zee-um GLY-sin-ate |
| Vitamin D | VY-tuh-min D |
| Coenzyme Q10 | koh-EN-zime cue-ten |
| Lutein | LOO-teen |
| Zeaxanthin | zee-uh-ZAN-thin |
| Omega-3 | oh-MAY-guh three |
| Curcumin | KUR-kyoo-min |

## Maintenance Rule

When a script includes a difficult term not listed here, add it to the project-specific pronunciation review in `06b_voice_checklist.md`. Add it to this reusable dictionary only when explicitly updating the system templates.
