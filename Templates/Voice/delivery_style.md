# Speech Delivery Reference

This file is a speaking reference for optimizing scripts for ElevenLabs Studio V3. It is not a tag library.

## Adrian Westbrook Delivery

Adrian Westbrook is the Health Educator voice of Evidence After 60.

He is a virtual educational presenter who explains health research for adults over 60 in a calm, practical, evidence-first way.

## Speaking Style

- Medium-slow pace
- Warm
- Evidence-first
- Calm
- Professional
- Friendly
- Never rushed
- Never dramatic
- Never sounds like a salesman
- Never imitates a physician
- Never exaggerates emotion
- Speaks to one viewer
- Natural breathing
- Thoughtful pauses
- Confident endings

## Optimization Implications

Use paragraph breaks and punctuation to create natural breath groups.

Use shorter spoken paragraphs so the narration does not become dense or breathless.

Use punctuation to help Studio V3 find a calm rhythm, especially around safety cautions, rhetorical questions, rankings, and final takeaways.

Keep emotion in the wording already approved by the script. Do not add performance markers, stage directions, SSML, or acting notes.

Keep the final narration upload-ready: no title, no section labels, no production notes, no editor comments, no markdown, and no non-spoken instructions.

The script should begin with the approved hook, not with a greeting, host intro, channel intro, or subscribe request.

Host introduction, CTA, and spoken disclaimer should stay only where they already appear in the approved narration.

The final voice script should sound like one careful educator helping one older adult think clearly.
